What it is

Three things, in order

It is a small app that runs on your computer and opens in your browser. Everything it does fits under one of these.

01Write

Say what you want the way you would tell a coach. Race, weeks, days you can run, what to avoid. The AI writes a full block: dates, sessions, steps, targets in your zones. Or start from a template and set the dates.

02Review

Every plan goes through the same checks before it goes anywhere. You see the sessions drawn by effort, the warnings with the dates to look at, and you can edit, drag, undo, or preview a session screen by screen as the watch will show it.

03Send

One click uploads the sessions to Garmin Connect and schedules them. Your watch picks them up on its next sync. Edit the plan later and send again; the workouts update in place instead of piling up.

What you need

A checklist before you start

  • A Garmin that accepts structured workouts. Fenix 6, 7 or 8, Epix, Forerunner 255, 265, 955 or 965, Edge 530 and newer. Older models like the Forerunner 235 or Vivoactive 3 cannot run structured workouts at all, so this will not help there.
  • Your Garmin Connect login. The same email and password you use in the Connect app. If you have two-factor turned on, the app asks for the code when it sends.
  • A computer. Windows, macOS or Linux, and about ten minutes for the install and first plan.
  • An AI key, if you have one.optional Claude, ChatGPT or Gemini keys make plan writing automatic. Without one, pick paste: the app gives you the prompt, you drop it into whichever assistant you already use, and paste the answer back. Same checks, same watch.
  • A recent hard race or time trial. Any distance, any date in the last few months. That one time is what the app uses to work out your training paces.
Install

Three commands, then it opens by itself

The app is installed with uv, a small tool that also fetches the right Python for you. You never touch Python directly.

Install uv

# in PowerShell
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
# in Terminal
curl -LsSf https://astral.sh/uv/install.sh | sh

Then close the terminal window and open a new one, so it knows where uv lives.

Install the app

uv tool install git+https://github.com/palatter/garmin-plan-push

This downloads the app and everything it needs into its own folder. It does not change anything else on the computer.

Open it

gpp web

Your browser opens on the app. Leave the terminal window open while you use it; closing it closes the app. Next time, it is the same one command.

Later, uv tool upgrade garmin-plan-push updates it, and gpp doctor checks that the profile, any AI keys and Garmin are all set up. If gpp is "not recognized" right after installing, open a new terminal window first; on Windows, uv tool update-shell fixes the path for good.

First run

Your paces, from one race

The first screen asks for a name and a race you ran hard: distance and time, for example 10k, 47:30. From that it works out your threshold pace and every training zone, and shows them as you type. You can also enter a threshold pace directly, or a lactate-threshold heart rate and max heart rate if you train by heart rate.

Under About your training it asks what a coach would ask, all optional: your goal race and its date, how many days a week you can run and how long on weekdays and weekends, which day the long run goes, your longest recent run and typical weekly volume, injuries, and standing rules such as "no hills for six weeks" or "keep Mondays easy". Everything you enter goes into every plan the AI writes and into the checks that judge it.

You can change any of it later from the profile chip in the top bar.

Write a plan

Describe it the way you'd tell a coach

Type what you want in the box. Be as specific or as vague as you like: "Eight weeks to a half marathon. Four runs a week, long run Sunday, one threshold session, nothing hard on Mondays." The chips under the box give you a starting point, and Open a template lists ready-made blocks and sessions you can date and use as they are.

Pick who writes it under Written by:

Paste
No key needed. The app builds the full prompt with your paces, dates and rules. Copy it into ChatGPT, Claude, Gemini, Copilot, anything. Paste the reply back. The app validates it and shows the plan.
Claude, ChatGPT, Gemini
Automatic. Set the one key you have once (see below), restart the app, and it preselects that provider. The plan streams in and the app reports what the call cost.
Local model
Through Ollama on your own machine. The app can measure whether a given model is good enough to follow the plan format before you rely on it.
# set the one you have, then restart the app
setx ANTHROPIC_API_KEY sk-ant-...   # Claude      (Windows; on macOS/Linux: export ANTHROPIC_API_KEY=...)
setx OPENAI_API_KEY sk-...          # ChatGPT
setx GEMINI_API_KEY AIza...         # Gemini

Whatever writes it, the plan is treated the same way: it must fit the plan format, and it goes through the checks. When a check finds something blocking, the app sends the finding back to the AI as a correction and asks again, up to a few times, before showing you the result.

Sanity report
What the checks found, with dates. A long run that jumps past anything in the last month, a weekly ramp over 25%, hard days back to back, a taper that cuts too little or too much, a race too close to your goal race, anything that breaks your own rules. Warnings are for you to judge; blocking findings never reach the watch.
Plan health
Every week as a bar: height is volume, colour is the share of hard running. Below it, load focus splits the recent weeks the way Garmin's watch does: low aerobic, high aerobic, anaerobic.
This week
The days ahead with the key session, the next phase change and the days left to your race.
Edit
Any session: the date, the name, the one line that goes on the wrist, a cue per step, or retype the whole session in one line, like 15m wu, 5 x 1km @ T w/ 2m jog, 10m cd.
Calendar
Drag a session to another day, or use Move… on the card. The checks re-run and the weekly totals update straight away.
Changes
Everything you changed since the plan was written or last sent, with undo and reset.
Missed and Pause
Missed a session? Readapt moves or drops what is around it by a stated rule and tells you why; Keep leaves the plan alone. Pause for an illness or holiday shifts everything and eases the first week back.
Hot day
Enter today's temperature and humidity and every pace target is shown slowed for the dew point, without changing the plan.
Export
The plan as a calendar file for Google, Apple or Outlook, as Markdown, CSV or a share bundle for a friend; one session as a Garmin FIT file or in the formats other training apps read.
Send

To the watch

Press Send to Garmin, enter your Garmin Connect email and password, and type the two-factor code if Garmin asks for one. The app signs in, uploads each session as a structured workout, schedules it on your Connect calendar on the right day, and reads each one back to make sure Garmin stored exactly what was sent.

Then sync your watch as usual, with the Connect app on your phone or Garmin Express. Each session appears on the day it is planned, with the steps, the pace or heart-rate targets and your cues, and the watch guides you through it like any Garmin workout.

Change the plan later and send again: the app updates the existing workouts in place rather than creating duplicates. To take a plan off the calendar entirely, gpp unpush plan.json in the terminal removes exactly what it put there and nothing else.

The password is used for that one sign-in and is not written to disk. What persists is Garmin's own login token, kept in a folder on your computer, so the next send does not ask again.

After the plan

It keeps working once the runs are done

Run gpp sync in the terminal now and then, and the app pulls your runs and daily metrics from Garmin into a local history. From then on each past session shows a one-line recap against what was planned, a plan-versus-actual graph appears beside plan health, and gpp today tells you when the day's session deserves to be easier, with the reason, never a silent rewrite.

None of the adaptation is automatic. Every change the app proposes is a stated rule, shown with its reason, and you can undo it. Two things most training apps do are deliberately left out because the evidence does not support them: the acute-to-chronic workload ratio and the 10% rule as hard gates.

Your data

It stays on your computer

What that means in practice

  • There is no server and no account. The app runs on your machine and only your own browser can talk to it.
  • Your paces, plans, history and settings live in a folder in your user profile. Nothing is uploaded anywhere, and nothing is collected.
  • Your Garmin password is used to sign in and never saved. Only Garmin's login token is kept.
  • If you use an AI key, the prompt goes to that provider and nowhere else. With the paste option, nothing leaves the app at all.
  • Sharing a plan with a friend sends zone names, not your paces. They get the same plan at their own paces.

Two honest caveats

  • The Garmin connection uses the same unofficial interface the Connect website uses, not an official partner API. It has been stable for years, but Garmin can change it. This is fine for your own account; it is not something to build a service on.
  • It is a tool, not a coach and not a doctor. The checks are the guardrails with evidence behind them, and they will tell you when a plan looks risky. Whether to run it is still your call.
If something goes wrong

The usual fixes

"gpp is not recognized" right after installing
Open a new terminal window; the old one does not know about uv yet. On Windows, run uv tool update-shell once if it still does not work.
Not sure what is set up
gpp doctor checks the profile, each AI key and the Garmin token, and says what to fix. gpp doctor --ping proves each AI key and model actually answer.
Garmin sign-in fails, and it worked before
Garmin expires its login tokens without warning. The error names the folder holding the old token; delete it and send again to sign in fresh.
The AI's answer is rejected
It happens with the paste option when the reply is not the plan format. Paste the app's message about what was wrong back into the same chat and ask for a corrected version; the app accepts the fixed reply.
Sessions do not show on the watch
Check they are on the calendar in the Connect app first. If they are, sync the watch again; if they are not, the send did not finish, and the log in the send dialog says where it stopped.
Reporting a bug
gpp doctor --bundle writes a diagnostics file with versions and the shape of your profile, and no credentials or plan contents. Attach it to an issue on GitHub.
